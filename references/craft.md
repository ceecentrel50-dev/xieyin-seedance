# 台词与表演：让人物像人，让模型能演

## 1. 一句台词 = 动作 + 语气 + 话

语料里没有一句是光秃秃的台词。公式：

```
[角色][具体动作][语气/表情][说/问/答]："[台词]"
```

语料实例（逐字）：

- `B咬了一口炸鸡漫不经心的说到："急啥，大震跑不了，小震..."`
- `B眼睛快速向右上方瞟了一下，随后B一本正经的解释："因为你属鸡，我属狗，我们在一起会鸡犬不宁。"`
- `A一边擦泪一边问："呜呜呜，那我算什么？"`
- `B摸了摸鼻子眼神躲闪回答："算前女友。"`
- `A一只手捂着胸口像是非常心痛，A问："那我们之间的回忆算什么？"`

**为什么必须写动作**：模型不会演"他很心虚"，但会演"摸鼻子 + 眼神躲闪"。
情绪要通过**身体**下达，不能通过形容词下达。

## 2. 微表演动作词库（从语料抄的，直接用）

| 情绪 | 可演的动作 |
|---|---|
| 心虚 / 撒谎 | 眼睛快速向右上方瞟一下、摸了摸鼻子、眼神躲闪、撅了撅嘴 |
| 无所谓 | 漫不经心、咬了一口、双手搭在沙发上、头也不抬 |
| 震惊 | 猛地一拍自己的脑袋、身体后仰、双手在前做出格挡的动作、满脸害怕 |
| 崩溃 / 委屈 | 泪水止不住的流、一边擦泪、一只手捂着胸口、更委屈更难过 |
| 搞笑收尾 | 像傻子一样嘿嘿笑了两下、拍了拍屁股、灰溜溜的跑了、脚趾抠地 |
| 强撑 | 硬梗着脖子、掏出道具、抬起做出瞄准的姿势 |

**每个动作只能出现一次。** 一条 30 秒的片子里塞五个"拍脑袋"，人物就变成了抽帧。

## 3. 三条节奏规则

1. **快问快答**：对手戏的来回要短。平均单句 28 字，超过 37 字就得拆。
2. **一个人不要连说三段**。语料里最多连说两句，第三句必须换人或者插入动作。
3. **引爆前留半秒静止**。争吵到顶 → 全场安静 → 动作发生。
   原文写法：`空气安静两秒，A和B一只手捂鼻子一只手指着C哈哈大笑了起来。`

## 4. 让观众先于角色知道真相

这是语料里最高级的一个手法，`grievous` 那条用得最狠：

```
B平静说："我们分手吧。"
A震惊："为什么？"
切B眼睛快速向右上方瞟了一下 → 观众已经知道她要胡扯了
B一本正经："因为你属鸡，我属狗，我们在一起会鸡犬不宁。"
```

**先给一个暴露"这人在胡说"的微表情，再让他一本正经地胡说。**
观众笑了，角色还没反应过来——这个时间差就是笑点。

同款：`A说出"去游乐园啊"之后突然意识到问题，神情僵住`——
角色自己先发现漏洞，观众跟着二次发笑。

## 5. 书面语黑名单

写完逐条搜，见一个改一个：

| 别写 | 改成 |
|---|---|
| 表示不满 | 不乐意了 |
| 随即 / 随后 / 紧接着 | 跟着 / 然后 |
| 十分惊讶 | 愣住了 |
| 愤怒地说 | 急了："……" |
| 该选手雄心壮志非常足 | 这选手心气儿真不小 |
| 进行打捞作业 | 往上捞 |

**例外**：主持人/解说员角色的台词可以书面一点，那是人设的一部分
（`看来这位选手雄心壮志非常足啊`）。主角不行。

## 6. 方言：只给一个人，只给一种

规则（语料实证）：

- A、B 说陕西话时，C 说河南话 / 广普 → 最多两种
- 方言只用来**制造错位**，不用来做考据
- 伦敦腔播报**永远不参与**方言混战
- 只在"某个方言词天然比普通话更贴英文发音、且不查资料就懂"时才用：
  可用池只有 `俺 额 啥 咋 嘞 中 恁 儿`

`俺不能死 / ambulance` 是唯一正确用法——`俺` 比 `我` 更贴，且全国人民都懂。

## 7. 齐说句

固定格式：`"[本义]，[谐音]。"`

- 先本义，后谐音（观众需要先知道意思，才能听出谐音）
- 两人齐说时，前面必须有一句各自的铺垫，否则突然合唱很突兀
- 三人齐说时，先让其中一人表态，另两人附和（`A、B和C站在屏幕中间，一起说`）

## 8. 字数体检

写完把正片台词（不含白底复述）捞出来数：

- 总数 < 53 → 冲突没铺开，加一轮问答
- 总数 > 159 → 删形容词、删解释、删重复情绪
- 单句 > 37 → 拆成两句，中间插一个动作

## 9. 交付前最后三查（Seedance 专属）

1. **搜"秒""分钟""帧""时间码"**——一个都不能有。节奏靠动作顺序，不靠数字。
2. **搜平台名**（Seedance / 即梦 / 可灵 …）——提示词里不写模型名。
3. **看有没有空行、标题、序号**——交付是一整段，分段会被当成多次生成。

这三查机器会做（`check_script.py`），但交稿前自己扫一眼更快。
