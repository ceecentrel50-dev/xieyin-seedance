# 结构：五幕怎么排，节拍怎么数

## 0. 实测区间（由 `scripts/corpus_stats.py` 从 19 条语料算出，不许拍脑袋）

| 指标 | 最小 | P25 | 中位 | P75 | 最大 |
|---|---|---|---|---|---|
| 正片台词字数 | 53 | 71 | **84** | 94 | 159 |
| 正片台词条数 | 3 | 4 | **4** | 5 | 9 |
| 白底台词条数 | 1 | 1 | 3 | 3 | 3 |
| 最长单句字数 | 22 | 26 | **28** | 31 | 37 |

**怎么用**：写完数一遍。台词条数落在 3–6、总字数落在 60–120，就是最稳的区间。
超出 159 字不是"内容丰富"，是模型演不完。

## 1. 节拍公式：3 + 1

```
铺垫（3 轮正反打，每轮 15–25 字）
   → 引爆（1 个动作 / 1 件道具 / 1 个人闯进来）
      → 余波（在场者的反应，1–2 句）
         → 白底（1 人回扣 + 众人齐说）
            → 字卡 + 播报
```

19 条语料里，正片台词 3–9 条、中位 4 条，多数是 3–6 轮铺垫。
**铺垫的作用不是搞笑，是让观众相信这个空间和关系。**
笑点全部集中在引爆那一下。

## 2. 五幕的写法

### 幕 1｜合规头

逐字照抄 SKILL.md 里那段。唯一可变量是 `N张`、参考图映射、以及方言声明。

方言声明的写法（语料原文）：

```
A和B说陕西话，C说河南话。
```

放在合规头之后、【画面内容】之前。

### 幕 2｜场景与冲突

开头第一句必须同时给出 **空间 + 人物状态 + 一个具体的物**：

> A、B和C坐在麦当劳的餐厅里面，桌子上摆着六个汉堡和四份薯条以及三杯可乐
> 还有一盒炸鸡小吃，C手里拿着一个汉堡在大口吃着。

数字要具体（六个汉堡、四份薯条）。"很多吃的"这种模糊量词，模型会拍成一个空桌子。

冲突的三种来源：

1. **外部事件**：地震、赛车爆炸、虫子飞起来
2. **关系摩擦**：二舅又来蹭饭、分手、忘叫朋友去游乐园
3. **生理尴尬**：放屁、踩乐高、被辣到

### 幕 3｜引爆

| 转法 | 结构 | 语料 |
|---|---|---|
| 道具反转 | 冲突升到顶 → 掏出意外道具 → 局势翻转 | M14 玩具枪 |
| 共识反转 | 两个人一起做蠢事 → 第三人一句吐槽定性 | 两人一起吃炸鸡 |
| 真相揭露 | 旁观者误判 → 本人说出真相 → 前文全部重新解读 | 踩乐高 / 憋了个屁 |

**引爆必须由画面完成，不能由台词解释。** 让道具入画、让人摔倒、让虫子飞起来。

### 幕 4｜白底揭底

三种写法见 SKILL.md。选择规则：

| 情况 | 用哪种 |
|---|---|
| 这场戏有两个人对呛，白底由他俩收 | ① 双人空景入场 |
| 全场只有一个人是"讲道理"的角色 | ② 单人授课式 |
| 三人都在场且都要表态度 | ③ 三人齐说 |

**入场句的固定语序**：`切A和B从一片空白背景中的右侧走入画面，A边走边[动作]对着B说到："..."`。
必须是 **A 走 + A 说**。语料里有一条写反了（"切B和C走入"却让 A 开口），
模型会因此多切一个镜头——这是真实发生过的废片原因。

### 幕 5｜字卡 + 播报

```
随后硬切整个屏幕纯白背景，画面上方显示中文"[本义]"，正中显示英文"[en]"，
下方显示中文"[谐音]"，人物面部、发型与服装保持一致，避免肢体变形与多余物体。
画外旁白用标准的播音讲解音，标准伦敦腔，把英文和中文各朗读一遍。
```

版面（从上到下）：**本义 / 英文 / 谐音**。

三条与原始语料的差异，都是为了 Seedance 能一次渲染对：

1. **方位词在前**。语料是`[en]下方写着中文[谐音]`，方位后置且英文重复三次，
   模型容易读错层级。改成`画面上方显示中文…正中显示英文…下方显示中文…`。
2. **每个字符串用引号包住**，只出现一次。
3. **补一句防瑕疵**（面部/发型/服装/肢体），字卡镜头通常没有人物走动，
   但保留了人物一致性约束，避免切回来时脸变了。

详细版句式不同、版式相同：
`纯白背景上方显示清晰中文"[本义]"，中央显示英文"[en]"，下方显示中文"[谐音]"`，
然后单独一句播报"依次清晰朗读[en]、[本义]、[谐音]"。

## 4. 两个常见变体

### 变体一：授课式收尾（第二批已成主流，28/33）

结尾不写字卡，由一个人走到纯白背景前，像老师讲课一样把词念一遍：

```
切A一个人在一片纯白的背景中，带着喜剧荒诞的表情和语调面对镜头走来，
A像是老师在给学生上课一样说：[谐音]，[en]，[本义]。
说到[en]时A把手食指伸出指向天上。
```

三个固定件缺一不可：`一个人`（不许两个人一起走）、`像老师在给学生上课`、
`说到[en]时[手势]`。手势语料里只用两种：**食指指天**、**右手举向上空**。

**收益**：省掉字卡三行和伦敦腔播报，正片篇幅少一半，可以日更。
**代价**：少了"三行字卡"那张可截图的记忆钉。

上一版我写过"授课式不适合系列化"——**这句是错的**。第二批 33 条里 28 条用它，
而且是同一组角色连着拍，恰恰最适合系列化。

### 变体二：详细版（900–1100 字）

`alone`、`maybe` 两条是另一个粒度：开头不写"对应这个视频"，而是
`使用N张人物参考图作为唯一角色外观依据`，然后逐点写场景光感、微表演、
负面约束整段。特征是**把"怎么演"写死**，适合需要精修或重拍的镜头。

两者不要混：标准版追求一条过，详细版追求可控。

## 5. 第二批（33 条）的结构差异

| 维度 | 第一批 19 条 | 第二批 33 条 |
|---|---|---|
| 结尾 | 字卡 16 / 授课 3 | **授课 28 / 字卡 5** |
| 参考图张数 | 2 张 9 条、3 张 10 条 | 2 张 7 条、**3 张 25 条**、4 张 1 条 |
| 参考图类型 | 只有人物（+1 个道具） | **人物 / 场景 / 道具 / 宠物 四类** |
| 台词引号 | 基本都用 | **16 条裸写**（`A说：台词。`） |
| 分镜写法 | 叙述为主，`切` 用得少 | `切B近景`、`切A过肩镜头` 显式标景别 |
| 角色映射 | 相对固定 | **A/B/C 的身份每集可能互换** |

### 三条可以直接抄的习惯

1. **每集至少切三次景别**：中景交代空间 → 近景对呛 → 特写落梗。
   显式写 `切X近景`，比"然后两个人吵起来"更容易被模型执行。
2. **过肩镜头用来拍"谁在看谁"**：`切A过肩镜头，C单人近景`，
   一句话就把正反打的正反说清了。
3. **画外音解决"人不在画面里"**：`同时画外音C说：……`，
   避免为了让人说话而多切一个镜头。

### 第四种引爆：自食其果

前三种（道具反转 / 共识反转 / 真相揭露）之外，第二批常这么干：
**角色刚说完大话，现实立刻打脸**。

- 说"他只不过是新手" → 赛车当场爆炸
- 说"风哥单脚窝屎能行吗" → 厕所马上传来摔倒声
- 说"我看是危险" → 话音未落人就摔了

关键是**打脸要在同一场戏里、紧跟着发生**，隔一场就没劲了。

### 角色是位置，不是身份

同一批里，`B` 有时是女主蝶妹、有时是男配风哥；`C` 也来回换。
写新稿时**只看这一条自己的映射**，不要沿用上一条的人设。
