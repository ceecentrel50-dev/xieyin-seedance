# 谐音梗：怎么找、怎么判、有哪些不能用

## 0. 唯一正确的心法

**先有中文，后有英文。**

不要打开词典找"哪个单词听起来像中文"。要反过来：想一句**中国人真会在这个情境里
喊出来的话**，再去英文里找发音接近的词。语料 19 条全部是这么长出来的。

判据只有两条：**念出来像不像**，**这句话像不像人说的**。两条都过才动笔。

## 1. 三条发现路径

### 路径 A｜口语句尾法（命中率最高）

中文口语句尾常落在 **他 / 死 / 你 / 俺 / 儿 / 不 / 了**，
而英文词尾常见 **-t / -st / -nt / -dʒ / -n / -ʌm**，两者天然对得上。

先造句，再查词：

| 先有的中文 | 反查出的英文 | 本义 |
|---|---|---|
| 俺不能死 | ambulance | 救护车 |
| 肥死他 | feast | 大餐 |
| 辣不死他 | lobster | 龙虾 |
| 拍死他 | pest | 害虫 |
| 勾死他 | ghost | 鬼 |
| 插这儿 | charger | 充电器 |
| 不撸它 | brute | 野兽 |
| 俺必胜 | ambition | 雄心 |
| 爱过你 | agony | 痛苦 |
| 爱提分手 | artificial | 虚伪的 |

**"死"字诀**是这条产线的主力句式：`X死他 / X不死他 / 俺X死`。
原因是中文"死"（sǐ）正好压住英文的 -st、-s、-t 尾音。

### 路径 B｜名字法（最容易被忽略）

把角色**取名**取成谐音。语料里 `alone / 阿龙` 就是这么来的：
主角叫阿龙，一个人坐着，"阿龙"就是 alone。名字提前埋好，全片不用解释。

用法：先定英文词，再给角色起一个读音贴近的名字。适合做"系列固定角色"。

### 路径 C｜专有名词借音（可遇不可求）

`endure / 印度`：借一个已经存在的地名/品牌名/译名。这类梗**纯属巧合，不能倒推**——
不要拿中文译名去反查英文，绝大多数对不上。

## 2. 选词的四个判据（按顺序卡）

1. **首音节对齐重音**：谐音的第一个字要压住英文的重读音节。
   `September/舍`、`conference/开`、`ambulance/俺`、`feast/肥` 全部满足。
2. **音节数 ≤ 英文音节数 + 1**。超了就要"吞音"，观众听不出来。
   `feast`(1) → `肥死他`(3) 是极限，靠语义救回来。
3. **辅音簇必须用整音节接**，不要指望跨音节拼：`-st` 用"死"接，`-str` 用"死"接。
4. **语义能双关的，可以买回一个音节的宽容度**。
   `artificial/爱提分手` 单看发音只有 4 分，但"分手"正好是剧情，实际效果 6 分。

## 3. 评分（低于 4 分不要写）

| 分 | 标准 |
|---|---|
| 6 | 发音像 + 语义双关 + 中文口语自然 |
| 5 | 发音像 + 口语自然 + 能配一个具体道具 |
| 4 | 发音像 + 口语自然 |
| 3 | 勉强能用，需要剧情硬撑 |
| ≤2 | 只是有点像，不要用 |

**语义双关是 6 分和 5 分的唯一分界线**：谐音词的本义要能接上剧情。
`agony/爱过你` 之所以是王炸，是因为这场戏本来就是失恋。

### 同一个词，换谐音句（第二批的改写习惯）

| 英文 | 旧谐音 | 新谐音 | 差别 |
|---|---|---|---|
| earthquake | 饿死鬼 | **饿丝鬼** | 更口语，"丝"字更贴 /θ/ |
| ghost | 勾死他 | **勾丝他** | 同上 |
| maybe | 没必（要） | **没B** | 从"没必要"换成球鞋少个字母 B |
| alone | 独自一个人 | **阿龙** | 从"状态"换成"人名"，双关更紧 |

**改写法值得学**：同一个英文词，换一版谐音句就能再拍一条。
`maybe` 这条尤其聪明——把"没必"换成"没B"，直接挂在球鞋 logo 上，画面自带证据。

⚠️ `hangger` 是 `hanger` 的拼写错误。落地时写 **hanger**，
除非你就要保留这个错（错得一致也算一个梗，但字幕会显得不专业）。

## 5. 扩展池（未实战，必须你念出声确认）

6 分：`September/舍不得/九月`、`conference/开饭了/会议`、
`university/由你玩四年/大学`、`compare/堪比呗/比较`、`destiny/等缘分/命运`

5 分：`umbrella/俺不来了/雨伞`、`strong/死壮/强壮的`、`income/硬抗/收入`、
`Africa/俺服了/非洲`、`colleague/俺坑你/同事`、`economy/依靠农民/经济`、
`pregnant/扑来个男的/怀孕的`、`holiday/耗了一天/假日`、`January/煎饼/一月`、
`monday/忙得/星期一`、`delay/滴泪/延误`、`legend/来真的/传奇`、
`ashamed/额想死/羞愧的`、`engineer/俺家牛儿/工程师`、`mortgage/摸给纸/房贷`、
`audit/讹到底/审计`、`dentist/等她死特/牙医`

**这些是"按规律推的"，不是"验证过的"。** 用之前必须自己念一遍。
谐音是听觉的，不是字符串的。

## 6. 明确不要做的三件事

- ❌ **不要用程序自动判断谐音好坏。** 试过"声母骨架 LCS"方案，把 `ambition/俺必胜`
  判成 0%，把 `butterfly/黄油飞` 判成失败。机器判不了听觉。
- ❌ **不要用中文译名倒推英文。** `endure/印度` 能成是巧合。
- ❌ **不要为了用某个梗去编一句没人会说的话。** 中文不自然，梗再准也是废的。
