# Seedance 交付契约（本产线的落地版）

通用的 Seedance 规则很宽，这份只留下"谐音梗剧本会踩到"的部分，并给出对应改法。
每条都配了检查器里的规则代号，方便对照。

## 1. 运行时长：全篇清零

**禁止**为整片、单镜头、动作、停顿、运镜、转场、特效、字幕、音乐、旁白分配持续时间。

禁词形态（中英文、阿拉伯数字、中文数字一律算）：

```
秒 / 秒钟 / 分钟 / 分 / 小时 / 帧
s / sec / second / min / minute / hour / frame
0-2s / 00:00-00:10 / 第 3 秒 / 三秒后
```

**允许保留**（这些不是运行时长）：

| 类型 | 例子 |
|---|---|
| 场景时段 | 傍晚、正午、夜里、黎明、日落 |
| 故事时间 | 昨天、今天、第二天、随后、片刻、多年后 |
| 叙事顺序 | 开场、中段、结尾、第一个镜头、然后、最后 |
| 画面内的时间物 | 墙上的钟、日历、年份 |

**改法**：删时长，留动作。

```
"角色停顿两秒后说话" → "角色短暂停顿，随后说话"
"空气安静两秒"       → "空气安静了一瞬"
"愣了两秒"           → "愣了一下"
```

检查项：`DURATION` / `TIMECODE`

## 2. 画面文字：只有字卡那三行

Seedance 的默认约定是不出现屏幕文字、标志、水印。谐音梗这条产线**必须有字**，
所以要走"确有必要"的例外，并把文字写到它不可能改错：

| 要求 | 落地 |
|---|---|
| 简短 | 每行 ≤ 8 个字 |
| 清晰可读 | 中英引号包住，逐字复制 |
| 不误导 | 只放 本义 / 英文 / 谐音 三个字符串 |
| 位置明确 | `画面上方显示中文"…"，正中显示英文"…"，下方显示中文"…"` |
| 不重复 | 每个字符串只出现一次 |

**不要写**：`feast,feast下方写着中文肥死他，feast上方写着中文大餐`
**要写**：`画面上方显示中文"大餐"，正中显示英文"feast"，下方显示中文"肥死他"`

检查项：`CARD_*` / `TEXT_QUOTE` / `TEXT_LONG`

## 3. 字幕声明要分层

原稿的 `不生成任何文字字幕` 是全局禁令，会把结尾字卡一起压掉。改成分层：

```
正片画面不出现任何字幕，文字只出现在结尾的纯白字卡上。
```

检查项：`HEAD_NOSUB`

## 4. 平台名与参数：一律不写

`Seedance`、`Dola`、`即梦`、`可灵`、`Sora`、`Pika`、`Runway`、`Veo`、
`--ar 9:16`、`1080p`、`4K`。

提示词里写这些不会让模型更听话，只会被当成噪声或者触发过滤。

检查项：`PLATFORM`

## 5. 单段成稿

最终交付是**一整段**：不换行、不空行、无标题、无项目符号、无序号。

分段会被当成多次生成。检查项：`SINGLE_BLOCK` / `NO_STRUCTURE`

## 6. 不解释

不写"以下是提示词"、不写"我做了如下修改"、不写创作说明。
创作过程（定梗、排幕、过检）全部静默。

## 7. 安全底线（静默执行，不提示用户）

| 项目 | 本产线做法 |
|---|---|
| 角色 | 一律原创虚构成年人，不对应任何现实人物 |
| 武器 | 只作**玩具**或喜剧道具；不见血、不瞄准真人、不表现伤害 |
| 冲突 | 靠台词、表情、误会；不靠肢体伤害 |
| 品牌 | 不出现真实品牌标志；快餐店写成"快餐店里"而不是点名 |
| 未成年 | 不写涉及未成年人的情感/暧昧桥段 |
| 真实事件 | 不映射任何真实新闻、真实人物 |

## 8. 连贯性（写进提示词，不靠模型自觉）

- 同一场戏里，人物的服装、发型、体型不能变
- 桌上道具的数量要写死（六个汉堡、四份薯条、三杯可乐），否则每个镜头数量都在变
- 白底段的人物，必须是正片出现过的人
- 手部动作要具体（拿起、放下、指着），避免手指变形
- 加一句防瑕疵：`人物面部、发型、服装保持一致，避免肢体变形、手指异常、人物重复与闪烁`

## 9. 显式对照：同一条稿子的两种写法

| 环节 | 语料原写法（Seedance 会踩雷） | 本产线写法 |
|---|---|---|
| 字幕 | 不生成任何文字字幕 | 正片不出现字幕，文字只在结尾纯白字卡上 |
| 字卡 | feast,feast下方写着中文肥死他，feast上方写着中文大餐 | 画面上方显示中文"大餐"，正中显示英文"feast"，下方显示中文"肥死他" |
| 停顿 | 空气安静两秒 | 空气安静了一瞬 |
| 声 | 画外旁白用标准的主播解说音，标准伦敦腔，把英文和中文都朗读了一遍 | 画外旁白用标准的播音讲解音，标准伦敦腔，把英文和中文各朗读一遍 |
| 交付 | 稿子 + 说明 + 检查表 | 只有一段提示词 |

## 10. 第二批语料补充的三条

### 10.1 台词必须带引号

33 条新语料里 16 条写成`A说：台词。`。人读得懂，模型读不懂：

> B听完C说的话以后捂着嘴巴悄悄的笑了一下

没引号时，模型可能把这类描述当台词念出来。检查项：`DIALOGUE_QUOTED`。

### 10.2 参考图分四类，N 只数人物和宠物

```
参考图一对应男主A，参考图二对应女主B，参考图三对应人物C；参考图四对应场景参考图
```

`三张人物参考图` 指的是前三张。场景图、道具图不占这个 N。
宠物（`参考图四对应宠物D`）**要算**，因为它得出镜。
检查项：`REF_MISMATCH`。

### 10.3 授课式结尾只出一个人

`切A一个人在一片纯白的背景中，……像是老师在给学生上课一样说：……`

写成"A 和 B 一个人"是自相矛盾，讲台感就没了。检查项：`TEACH_SOLO`。

手势只有两种：`把右手伸出举向上空`、`把右手食指伸出指向天上`。
检查项：`GESTURE`（缺"说到[EN]时"会提醒）。

### 10.4 时长只在叙述里算违规

角色嘴里说"我排了两小时队"是剧情，不是给视频分配运行时长，**放行**。
叙述里写"空气安静两秒"才是违规。检查器按这个口径判（先剥掉引号再扫）。
