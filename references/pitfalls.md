# 废片清单：这些错会直接毁掉一条片子

先说一件要紧的事：**语料自己也有 bug，照抄会连 bug 一起抄下来。**
下面标"语料实测"的，都是从你原来那 19 条里逐字查出来的。

## A. 结构类

### A1 白底换人（语料实测）

原文：`切B和C从一片空白背景中的右侧走入画面，A边走边指了指自己的肚子……`

走进去的是 B 和 C，开口的是 A。模型会拆成两个镜头，或者让 C 说话。
**规则**：谁走，谁就必须是第一个开口的人。走两个人，说话的人必须在这两个人里。

### A2 参考图数 ≠ 角色数（语料实测）

`earthquake` 那条声明"两张人物参考图"，但正片里 A、B、C 三个人都在说话。
第三个人没有外观依据 → 脸崩，或者干脆变成另一个人。

| 情况 | 后果 | 改法 |
|---|---|---|
| 声明 2 张，却有 3 人说话 | 第三人没有外观依据，脸会漂 | 补第三张图，或删掉 C 的台词 |
| 声明 3 张，只有 2 人说话 | 模型为"用上"第三张图而凭空造人 | 减到 2 张，或给 C 加戏 |
| 有第三人不说话（背景板） | 观众会等着他开口，节奏塌 | 要么给戏，要么删掉 |

**例外**：参考图给道具（`参考图三为A手里的道具玩具`）时，角色数 = 图数 − 1。

### A3 谐音句只出现在白底

正片里没人喊过这个词，白底突然齐说"饿死鬼"——观众反应是"什么鬼"。

**必须两段式**：正片里角色自然喊一次（观众当成普通台词），白底再复述一次（恍然大悟）。
白底那句要和正片那句**字面几乎一样**。

### A4 铺垫不足就引爆

3 轮以下的正反打，观众还没认全人，笑点就来了。
反过来，超过 6 轮铺垫，30 秒的片子会显得拖。

### A5 场景太抽象

`在一个房间里` → 模型拍一个白墙。必须给**具体的物**：
六个汉堡、四份薯条、三杯可乐、一盒炸鸡小吃、一张摊开的单词书、脚边散落的乐高零件。

## B. 台词类

### B1 人称错位（语料实测）

原文：`A表情由赞同转变为略微为难的对A说` —— 自己对自己说。
`s 对A说 / 对B说` 每次写完都要核对一遍主客。这类错在长稿里极易发生。

### B2 书面语混入

`该选手雄心壮志非常足` 只能给主持人。主角说这种话，观众立刻出戏。

### B3 台词超长

单句 > 37 字，模型口型对不上，或者直接吞掉后半句。
正片台词总量 > 159 字，30 秒根本说不完。

## C. 格式类

### C1 字卡三行缺一

缺"本义"→ 观众不知道这词什么意思；缺"谐音"→ 笑点没有落点；
缺英文 → 整条片子白拍。

写法用方位句：`画面上方显示中文"[本义]"，正中显示英文"[en]"，下方显示中文"[谐音]"`。
不要写成 `[en],[en]下方写着中文…，[en]上方写着中文…`——方位后置、英文重复三次，
模型会读乱层级。

### C1b 字符串没加引号

19 条语料里，**48 处**字卡字符串是裸写的。裸字符串模型会自由改写
（"俺不来了"变成"我不来了"，"肥死他"变成"胖死他"）。
**每个字符串必须用中文引号包住**，且每行 ≤ 8 个字。

### C2 谐音词写残（语料实测）

`maybe` 那条卡片上写"没必"，实际台词是"没必要"。**卡片上的词必须是完整的、能读出口的词。**

### C3 字幕声明写成了全局禁令（语料 19/19 中招）

原文`不生成任何文字字幕`是全局禁令，和结尾的三行字卡直接冲突，
模型常常选择"听禁令"，把字卡一起压掉。必须分成两层：

```
正片画面不出现任何字幕，文字只出现在结尾的纯白字卡上。
```

### C3b 写进了运行时长

`空气安静两秒`、`愣了两秒`、`隔两秒哀嚎一嗓`——这类写法在 Seedance 里属于
给动作分配运行时长，整条提示词会被判不合规。改成`一瞬`、`愣了一下`、`隔一会儿`。
**删时长，不删动作。**

### C4 混进软转场

`淡入淡出`、`溶解`、`叠化`、`闪白`、`推拉转场` —— 一个都不许出现。
只有硬切，全片都是硬切。

### C5 引号开闭混乱（语料实测）

语料里 `“ ... " ... ”` 三种引号混用。人读没问题，但脚本和模型都会解析错。
**新稿统一用 `“ ”`。**

## D. 声音类

### D1 忘了伦敦腔

`画外旁白用标准的主播解说音，标准伦敦腔` —— 这是音色签名，不是可选项。

### D2 方言给太多人

三种以上方言，观众听不清，笑点直接漏。上限两种，且只给一个人。

## E. 第二批才暴露的坑

### E1 台词不加引号（33 条里 16 条）

写成`A说：台词。`，模型会把描述也念出来：

> A摇摇头有点悲伤得把相框放在了架子上 → 这句不该被人念出来

**所有台词用中文引号包住**，描述留在引号外。这是新批次最值得改的一条习惯。

### E2 参考图张数算错

`使用三张人物参考图…参考图四对应场景参考图` 是对的（3 人物 + 1 场景）；
但如果写成`参考图一为人物A。参考图二为人物B。` 却声明"三张"，就是真错。
**N = 人物数 + 宠物数**，场景图和道具图不占 N。

### E3 授课式写成两个人一起走

`切A和B一个人在一片纯白的背景中` —— 自相矛盾。
授课式只能**一个人**，因为它是"老师讲课"，两个人就没有讲台感了。

### E4 手势写成了别的

语料里只有两种手势：`把右手伸出举向上空`、`把右手食指伸出指向天上`。
写成"挥了挥手""比了个耶"就不是这个系列的东西了。

### E5 角色身份套错

上一集 A 是红狼、B 是蝶妹，这一集可能反过来。
**照这一条自己的映射写**，不要凭记忆套人设。

## 交付前最后一遍

```
python scripts/check_script.py 你的稿子.md
```

它会拦下上面 A1–A4、B3、C1–C5、D1、E1–E3 里的可机器判定项。
**拦不住的只有"谐音像不像"和"这句子像不像人说的"——这两条必须你自己念出声。**
