# 谐音梗 × Seedance

**给一个三元组，还你一条能直接粘进 Seedance 的完整提示词。**

```
dangerous | 危险的 | 单脚窝屎
╰─ 单词 ─╯ ╰ 翻译 ╯ ╰─ 谐音句 ─╯
```

这是一个**剧本生成 skill**：输入「单词 / 中文翻译 / 中文谐音句」，
输出一段可直接投喂视频模型的竖屏喜剧提示词——30 秒、纯白底授课、伦敦腔收尾。

它不教英语，也不是在讲编剧理论。它只解决一件事：

> **谐音梗的结构，和 Seedance 的交付契约，是两套规矩。**
> 单独用任何一套都会在接缝上翻车。

---

## 它堵的五个接缝

| 接缝 | 常见写法 | 后果 |
|---|---|---|
| 运行时长 | 「空气安静两秒」「停顿三秒」 | Seedance 禁止给动作分配时长，整条判不合规 |
| 字卡层级 | `feast,feast下方写着中文肥死他` | 方位后置＋英文重复三次，渲染成错位文字 |
| 字幕声明 | 开头「不生成任何文字字幕」，结尾又要三行字 | 模型把结尾字卡一起压掉 |
| 台词没引号 | `A说：台词。` | 模型分不清哪句要念、哪句是动作描写 |
| 交付形态 | 附上 beat sheet、检查报告、修改说明 | 交付只收一段，多出来的都是噪音 |

每一条都对应检查器里的一条规则，不是空话。

## 快速开始

```bash
git clone <本仓库>
cd xieyin-seedance

# 1. 三元组生成骨架
python scripts/make_skeleton.py "dangerous|危险的|单脚窝屎"

# 2. 把【场景】【台词】填进去，存成 draft.md

# 3. 过自检
python scripts/check_script.py draft.md
```

`[PASS] draft.md  正片 4 句 / 74 字 / 最长 24 | 参考图 3 | 说话人 ABC` 就算过。

之后说一句「按 xieyin-seedance 的方式，把 单词-翻译-谐音 做成剧本」就会触发。

## 从谐音句倒推场景

这是整套方法里唯一真正要动脑的一步。

谐音句本身就是一句「人在某个时刻会脱口而出」的话。
**找到那个时刻，场景就自己长出来了。**

| 三元组 | 谁会喊 | 场景 | 引爆 |
|---|---|---|---|
| dangerous / 危险的 / 单脚窝屎 | 腿伤还要单脚蹲坑的人 | 客厅，朋友看他拄拐去厕所 | 厕所传来摔倒声 |
| cantaloupe / 哈密瓜 / 看他老婆 | 被抓包的男人 | 超市水果摊 | 手里的哈密瓜被一拳打烂 |
| holiday / 假日 / 耗了一天 | 被排队折磨的游客 | 景区长椅，导游举小旗 | 最后一项还要排到腿软 |

反过来先想场景再硬塞谐音，台词一定会变成解释句（「这可真是 dangerous 啊」），观众不笑。

## 自检器不是摆设

`check_script.py` 会拦：参考图张数与说话人数、白底谁走谁开口、谐音有没有在前文埋过、
字卡三行齐不齐、软转场、时长泄漏、平台名、单段成稿、台词引号、授课式单人、字数区间。

**但一个永远返回 PASS 的检查器，比没有检查器更糟。**

所以有 `selftest.py`：它故意造 23 种坏稿（白底换人、谐音未埋、软转场、悬空角色、
缺字幕声明、字卡缺本义、单句过长、台词超量、时长泄漏、分段成稿……），
每一种都必须被报出来。

```bash
python scripts/selftest.py
# 用例 23 个，失败 0 个。
# 自测全部通过。
```

它也明确**不管**两件事：谐音像不像、句子像不像人说的。这两条只能念出声。

## 数据从哪来

从 52 条真实语料反推：第一批 19 条（字卡为主）、第二批 33 条（授课式为主）。
文档里每一个区间都是脚本量出来的，不是拍脑袋写的：

| 指标 | 最小 | 中位 | 最大 |
|---|---|---|---|
| 正片台词字数 | 53 | 84 | 159 |
| 正片台词条数 | 3 | 4 | 9 |
| 最长单句 | 22 | 28 | 37 |

复现：

```bash
python scripts/corpus_stats.py assets/corpus.txt --table
python scripts/corpus_stats.py assets/corpus2.txt --table
```

**语料本身也有 bug。** 检查器在 52 条里抓出 11 处：声明 3 张参考图却只映射 2 张、
字卡字符串不加引号、叙述里写「两秒」、台词不足 3 句。
所以有句话写在 `SKILL.md` 里：别照抄语料，它会连 bug 一起传给你。

## 已知限制

- **谐音质量无法自动判定。** 试过声母骨架自动打分，把人工验证过的 6 分梗判成 0%，已废弃。
- **不保证成片效果。** 只保证提示词格式合规、结构完整，模型是否照此演出要看模型。
- **语料是中文互联网口语**，涉及方言梗时靠人判断，不做方言考据。
