# 填空模板（Seedance 直接可用）

**入口是三元组**：`【单词】 | 【翻译】 | 【谐音】`
例：`dangerous | 危险的 | 单脚窝屎`
先用 `python scripts/make_skeleton.py "dangerous|危险的|单脚窝屎"` 出骨架，再回这里对格式。

把 `【】` 换掉，其余一个字都不要动。成果必须是一整段，不分行、不空行。
**两条主线**：授课式（快、可日更）与字卡式（有记忆钉）。

---

## A. 授课版（默认，第二批 28/33 用这个）

对应这个视频使用三张人物参考图，角色为原创虚构的成年人物，不对应任何现实人物，不参考任何真人肖像，不复制任何名人的脸部特征：参考图一对应男主A，参考图二对应女主B，参考图三对应人物C；参考图四对应场景参考图。专业摄像头拍摄，视线高度接近人物眼睛，以中近景、近景、面部特写为主，两人对话采用快速正反打，全部使用直接硬切，正片画面不出现任何字幕，文字只出现在结尾。【画面内容】【空间 + 谁在哪 + 桌上具体的物件】。【A 的动作 + 语气】：“【第一句，15–25 字】。”切B近景，【B 的动作】：“【第二句，反驳或嘴硬】。”【引爆：一个可见动作发生 / 道具入画】。【在场者的即时反应，一句】。切【谁】近景，【谁】：“【第三句，把谐音句喊出来】。”切【结尾那个人】一个人在一片纯白的背景中，带着喜剧荒诞的表情和语调面对镜头走来，【他】像是老师在给学生上课一样说：【谐音】，【en】，【翻译】。说到【en】时【他】把右手伸出举向上空。

---

## B. 字卡版（要做截图记忆点时用）

对应这个视频使用两张人物参考图，角色为原创虚构的成年人物，不对应任何现实人物，不参考任何真人肖像，不复制任何名人的脸部特征：参考图一对应男主A，参考图二对应女主B。专业摄像头拍摄，视线高度接近人物眼睛，以中近景、近景、面部特写为主，两人对话采用快速正反打，全部使用直接硬切，正片画面不出现任何字幕，文字只出现在结尾的纯白字卡上。【画面内容】【空间 + 具体物件 + 谁在做什么】。【A 的动作 + 语气】：“【第一句】。”【B 的动作 + 表情】：“【第二句】。”【A 的反应动作】：“【第三句，推到顶】。”【引爆动作】，【即时反应，一句】。切A和B从一片空白背景中的右侧走入画面，【走前面那个人】边走边【回扣前文道具或动作】对着【另一人】说到：“【回扣台词】。”【另一人】得意的说到：“【二度嘴硬，把谐音句再念一次】。”说完以后，A和B站在屏幕中间，A和B一起说：“【翻译】，【谐音】。”随后硬切整个屏幕纯白背景，画面上方显示中文“【翻译】”，正中显示英文“【en】”，下方显示中文“【谐音】”，人物面部、发型与服装保持一致，避免肢体变形与多余物体。画外旁白用标准的播音讲解音，标准伦敦腔，把英文和中文各朗读一遍。

## C. 带宠物 / 带道具的写法（参考图超过人物数）

```
……参考图一对应男主A，参考图二对应女主B，参考图三对应人物C，参考图四对应宠物D。
```

或

```
……参考图一对应男主A，参考图二对应女主B；参考图三为A手里的道具玩具。
```

铁律：**`N 张人物参考图` 的 N 只数人物和宠物**，场景图和道具图不占 N。
正文里必须让宠物/道具真的入画，否则参考图白给。

## 交稿前对一遍

- [ ] `【】` 全换干净
- [ ] **全篇没有一个"秒/分钟/帧/时间码"**
- [ ] 一整段，没有空行、标题、序号
- [ ] 没有 Seedance / 即梦 / `--ar` 之类的平台名与参数
- [ ] **每句台词都用中文引号包住**
- [ ] 正片台词 3–6 条，总字数 60–120，最长单句 ≤ 37
- [ ] 谐音句在正片喊过一次
- [ ] 白底走的人＝第一个开口的人；授课式只出一个人
- [ ] 声明 N 张 = 人物数 + 宠物数
- [ ] 字卡版：三行齐全、各自带引号、每行 ≤ 8 字
- [ ] 字幕声明是分层的
- [ ] 全篇只有硬切

写完跑一遍：

```
python scripts/check_script.py 你的稿子.md
```
